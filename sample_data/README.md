# Representative Sample Data

This directory contains representative shaded-relief bathymetric
image patches and their corresponding pockmark annotations.

## Image size

512 × 512 pixels

## Annotation format

YOLO format:

class_id x_center y_center width height

All coordinates are normalized to [0, 1].

Class definition:

0: pockmark

## Data availability

These files represent a subset of the dataset used in the study.

The complete derived annotation dataset, precise patch-location
information, and full train/validation/test file lists are not
publicly released at the present stage.
